# Powertrain Database

This repository contains a technical database of current BMW, Mercedes-Benz and Audi powertrains, covering petrol and diesel engines, mild hybrids, plug-in hybrids and electric drives.
The goal is to compare these powertrains on a consistent basis, keeping manufacturer specifications strictly separate from my own calculations such as specific power (kW/l), specific torque (Nm/l) and mean piston speed.
The data is collected in Excel with a source for every value and analyzed with Python; the results are documented tables, charts and, later, an interactive Power BI dashboard.
